# Bundled voice library

这个目录随插件一起分发，包含 15 个 Breeze `.breeze` 音色文件：

```text
dafeiyu
dsh_voice
dsh_voice_clear
dsh_voice_sapi
ref01 … ref11
```

这些音色由本仓库项目所有者提供并授权随项目一起开源，作为本地语音通话的默认音色库。除非文件本身另有说明，音色文件与项目代码一样按 MIT 许可分发。

使用或再分发时请自行确认：

- 你拥有参考音频、音色样本和对应用途的权利；
- 不把音色用于冒充真实人物、欺诈或误导；
- Breeze 权重本身另有许可，不能把权重视为本项目 MIT 代码的一部分。

Breeze 权重不在本目录，也不在本仓库；安装器会按官方固定 SHA-256 单独下载。
